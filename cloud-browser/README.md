# المتصفح السحابي (Cloud Browser)

متصفح Chromium حقيقي يعمل على سيرفر سحابي مجاني. كل التصفح والتحميل وتشغيل الفيديو يحدث على السيرفر،
وهاتفك يستقبل **الشاشة والصوت كفيديو مضغوط** فقط.

- **حد الاستهلاك:** افتراضياً 50 MB خلال أي 60 دقيقة. عند 85% تتحول الجودة تلقائياً إلى «توفير»، وعند 100% يتوقف البث.
- **الجودات الواقعية:** توفير ≈ 27 MB/ساعة (360p)، متوازن ≈ 44 MB/ساعة (480p) وهو الافتراضي، عالٍ ≈ 1 GB/ساعة (720p، يتجاوز الحد ولذلك يتوقف تلقائياً).
- **لا يمكن** تحقيق 1080p ضمن 50 MB/ساعة. هذه حدود الرياضيات وليست قيوداً في الكود.

## الهيكل

| الملف | الوظيفة |
|---|---|
| `server.js` | خادم HTTP + WebSocket، يدير الجلسة والبث والأوامر |
| `lib/browser.js` | تشغيل Chromium والتحكم فيه عبر Chrome DevTools Protocol |
| `lib/stream.js` | ffmpeg: التقاط الشاشة (x11grab) والصوت (PulseAudio) وترميز H.264 + Opus، بمعدل ثابت |
| `lib/input.js` | الفأرة ولوحة المفاتيح عبر xdotool |
| `lib/security.js` | منع العناوين الداخلية (localhost، الشبكة الخاصة، عنوان الـ metadata) والمخططات الخطرة |
| `lib/budget.js` | عداد الاستهلاك المتدحرج على السيرفر |
| `public/` | واجهة الهاتف العربية (RTL) |
| `Dockerfile`, `docker-compose.yml` | صورة واحدة + نفق Cloudflare المجاني للـ HTTPS |

## التشغيل خطوة بخطوة (من الهاتف فقط)

> **قبل أن تبدأ، اقرأ هذا:**
> 1. **Oracle Cloud يطلب بطاقة بنكية (Visa/Mastercard) للتحقق من الهوية فقط.** لن يُخصم منها شيء مع موارد Always Free. لا تقبل البطاقات المسبقة الدفع أو الافتراضية (virtual) أو التي تحتاج PIN. إن لم تملك بطاقة مناسبة فلن تستطيع استخدام Oracle.
> 2. **طبقة Oracle المجانية خُفّضت:** الآن 2 OCPU و12 GB للـ ARM (بعد أن كانت 4 و24).
> 3. **لم أستطع التحقق** من أن Oracle يقبل التسجيل من السودان. إن رفضه، أخبرني لنبحث عن بديل.
> 4. **يوتيوب قد يعرض "تأكيد أنك لست روبوت"** لعناوين السيرفرات. هذا لا يمكن ضمانه.

### الخطوة 1: إنشاء حساب Oracle
افتح من متصفح الهاتف: `https://signup.oraclecloud.com` وسجّل، وأدخل بيانات البطاقة للتحقق.
اختر منطقة (Region) قريبة إن توفرت.

### الخطوة 2: إنشاء السيرفر المجاني
من لوحة Oracle: **Menu ☰ ← Compute ← Instances ← Create instance** واملأ:
- **Image:** Canonical Ubuntu 22.04 أو 24.04 (aarch64 / ARM)
- **Shape:** `VM.Standard.A1.Flex` ثم اضبط **OCPU = 2** و**Memory = 12 GB**
- **SSH keys:** اختر **Generate a key pair for me** ثم **Save private key** (سينزل ملف `.key` على هاتفك. احفظه)
- **Public IP:** فعّل Assign a public IPv4 address
- اضغط **Create**، وانتظر حتى تصبح الحالة Running، ثم انسخ **Public IP Address**.

> إن ظهر خطأ "Out of capacity" فهذا يعني أن ARM المجاني ممتلئ في تلك المنطقة. جرّب لاحقاً أو في Availability Domain أخرى.

### الخطوة 3: الاتصال بالسيرفر من Termius
1. حمّل تطبيق **Termius** (مجاني) من متجر Google Play.
2. **Keychain ← ＋ ← Import** واختر ملف `.key` الذي نزّلته.
3. **Hosts ← ＋ New host**:
   - **Address:** الـ Public IP
   - **Username:** `ubuntu`
   - **Key:** اختر المفتاح الذي استوردته
4. اضغط **Connect**. ستفتح نافذة أوامر.

### الخطوة 4: تثبيت Docker
انسخ والصق الأمر التالي (ينتظر دقيقة تقريباً):
```bash
curl -fsSL https://get.docker.com | sudo sh && sudo usermod -aG docker $USER && echo DONE
```
ثم أغلق الاتصال وأعد الاتصال من Termius (لكي تفعّل صلاحية Docker).

### الخطوة 5: تحميل المشروع
```bash
sudo apt-get install -y git && git clone -b arena/f6f3f8f7-project1 https://github.com/venom3-byte/Project1.git && cd Project1/cloud-browser && echo OK
```

### الخطوة 6: إنشاء مفتاح الدخول
```bash
./scripts/init-env.sh
```
سيطبع لك **مفتاح الدخول**. **انسخه واحفظه** (ستكتبه في الهاتف لاحقاً).

### الخطوة 7: التشغيل
```bash
docker compose up -d --build
```
> أول مرة تستغرق 10 إلى 20 دقيقة (تنزيل Chromium وبناء الصورة). انتظر حتى تنتهي.

### الخطوة 8: الحصول على الرابط
```bash
docker compose logs tunnel 2>&1 | grep -o 'https://[a-z0-9-]*\.trycloudflare\.com' | tail -1
```
سيظهر رابط مثل `https://xxxx-xxxx.trycloudflare.com`. **هذا هو رابطك.**

### الخطوة 9: الفتح من الهاتف
1. افتح الرابط في Chrome على هاتفك.
2. اكتب **مفتاح الدخول** من الخطوة 6 واضغط **دخول**.
3. اضغط **▶ ابدأ البث**.
4. اكتب في خانة الرابط أعلى الشاشة كلمة بحث أو رابطاً، واضغط **فتح**.

**التحكم:** لمسة = نقرة، سحب = تمرير. زر «كتابة» يفتح لوحة المفاتيح.

## ملاحظات مهمة
- **الرابط المجاني المؤقت** (`trycloudflare.com`) يتغير إذا أُعيد تشغيل نفق Cloudflare. إن أردت رابطاً ثابتاً تحتاج نطاقاً (Domain) مضافاً إلى Cloudflare، وهذا قد يكون مدفوعاً حسب الاسم.
- **تحديث المشروع:** `cd ~/Project1 && git pull && cd cloud-browser && docker compose up -d --build`
- **السجلات عند المشاكل:** `docker compose logs --tail=100 browser`
- **إيقاف كل شيء:** `docker compose down`
- **تغيير الحد:** عدّل `LIMIT_MB_PER_HOUR` في `.env` ثم `docker compose up -d`. من الهاتف يمكنك خفضه فقط.
- **Oracle قد يوقف السيرفرات الخاملة**. الاستخدام المتكرر يبقيها نشطة.

## استكشاف الأخطاء
| المشكلة | الحل |
|---|---|
| "المفتاح غير صحيح" | تأكد من المفتاح في `.env` (`cat .env`). بعد 5 محاولات خاطئة يُحظر الدخول 10 دقائق |
| الصفحة فارغة / لا يظهر الفيديو | `docker compose logs --tail=100 browser` وأرسل لي النتيجة |
| الصوت لا يعمل | تأكد أن الهاتف ليس على صامت، واضغط مرة على الشاشة بعد البدء |
| "تعذر إنشاء مخزن الفيديو" | متصفحك قديم. استخدم Chrome محدثاً |
| يوتيوب يقول "أنت لست روبوت" | قيد من يوتيوب على عناوين السيرفرات. لا حل مجاني مضمون |
